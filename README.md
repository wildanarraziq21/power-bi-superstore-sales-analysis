
# Superstore Sales & Profit Analysis Dashboard

## 1. Project Overview

This project presents an interactive business intelligence dashboard developed using Microsoft Power BI to analyze sales performance, profitability, customer segments, product categories, and regional performance.

The dashboard transforms retail transaction data into actionable business insights through data visualization, KPI monitoring, and interactive filtering.

## 2. Business Objectives

- Evaluate overall sales and profitability.
- Identify top-performing product categories and sub-categories.
- Compare business performance across geographical regions.
- Analyze customer segments and purchasing patterns.
- Understand the relationship between discount levels and profitability.

## 3. Dataset Description

The project uses the Sample Superstore dataset, containing retail transaction records with information about:

- Orders and shipping details
- Customer information
- Product categories and sub-categories
- Sales, quantity, discount, and profit
- Geographical information

## 4. Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Business Intelligence

## 5. Data Preparation

Data preparation was performed using Power Query, including:

- Data type validation and correction.
- Numeric and date formatting.
- Duplicate record inspection.
- Data quality checks.
- Preparing the dataset for analysis.

## 6. Key Performance Indicators (KPIs)

The dashboard includes five primary KPIs:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Total Quantity Sold

## 7. Dashboard Features

- Sales by Category
- Profit by Category
- Sales by Region
- Profit by Region
- Sales by Customer Segment
- Sales by Sub-Category
- Profit vs. Discount Analysis
- Interactive slicers for Region, Order Date, and Category

## 8. Key Business Insights

- Technology recorded the highest category sales at approximately $0.84M.
- Technology generated the highest category profit at approximately $145K.
- The West region achieved the highest regional profit at approximately $108K.
- Phones recorded the highest sub-category sales at approximately $330K.
- Higher discount levels tended to be associated with lower profitability, with some transactions resulting in negative profit.
